Android 8/API26+, WebView109+, `com.diskreid.vrcnextmobile`, versionCode16.
Подписанная тестовая debug-сборка с прежним сертификатом; устанавливается
поверх 0.2.12 без удаления данных.

- Исправлена подпись «На сайте» у находящихся в игре друзей в приватном
  инстансе, при переходе между мирами и при нераскрытом адресе.
- Посетители сайта с location: offline видны в «Друзья рядом» с кольцом.
  В счётчик «друзей в VRChat» входят только находящиеся в игре.
- Главная, индикаторы и полный профиль используют общие правила присутствия.
  Живые события обновляют данные; старый ответ обновления не перекрывает их.
- Карточки миров используют только раскрытые корректные адреса инстансов.
- Существующий дизайн, лента аватаров и данные сохранены. Обхода профилей нет.

Прошли 363 теста логики, 8
целевых проверок главной/друзей/профиля в двух ориентациях и
36 native JUnit. Android Lint:
0 ошибок / 9 предупреждений.
Полный набор UI в этом выпуске повторно не запускался.
Подпись, совместимость сертификата и все production assets APK сверены.
Физический телефон и живой VRChat-аккаунт здесь не проверялись.
