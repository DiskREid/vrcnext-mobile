# VRCNext Mobile 0.3.0

[Скачать APK](https://github.com/DiskREid/vrcnext-mobile/releases/download/v0.3.0/VRCNext-Mobile-0.3.0.apk) ·
[Исходники ZIP](https://github.com/DiskREid/vrcnext-mobile/releases/download/v0.3.0/VRCNext-Mobile-0.3.0-source.zip) ·
[Контрольные суммы](SHA256SUMS.txt)

Android 8/API26+, WebView109+, `com.diskreid.vrcnextmobile`, versionCode17.
Подписанная тестовая debug-сборка с прежним сертификатом; устанавливается
поверх 0.2.13 без удаления данных.

- Новый тёмный интерфейс с фиолетовыми акцентами, обновлёнными навигацией,
  карточками, формами и окнами в обеих ориентациях.
- 11 встроенных языков: русский, английский, японский, немецкий, французский,
  испанский, португальский, польский, итальянский, турецкий, украинский.
  Выбор применяется сразу и сохраняется; первый запуск следует языку телефона.
- «О проекте»: мобильная версия, DiskREid — стример, блогер и игрок VRChat,
  благодарности авторам VRCNext, исходники и VNCOL.
- [Поддержать DiskREid на Boosty](https://boosty.to/mr.diskreid): настоящий
  внешний переход по нажатию, без привязки к аккаунту или разблокировки функций.
- Пользовательские имена, био, названия и описания сохраняются в оригинале.
  Сессия, история, цвет акцента и настройка защиты скриншотов не сбрасываются.

Проверены 374 теста логики, 154 уникальных UI-сценария с повторной проверкой
двух случаев после исправления тестовых сценариев, отдельные 8 проверок языков
и проекта, 36 native JUnit. Android Lint: 0 ошибок / 9 предупреждений.
Все31 production-файл сверены с APK, подпись совместима с предыдущим выпуском.
[Точный отчёт](validation.json) · [Сборка и повторные проверки](../../docs/BUILD_REPORT.md).

Лог смены аватара остаётся нерешённым по результату пользователя. Этот выпуск
не объявляет его исправленным. Физический телефон и живой VRChat-аккаунт
здесь не проверялись. Некоторые названия инструментов и серверные сообщения
остаются на языке источника; профессиональная редактура всех переводов
носителями не выполнялась.
