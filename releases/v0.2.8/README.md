# VRCNext Mobile 0.2.8

[Контрольные суммы](SHA256SUMS.txt)

Android 8/API26+, WebView109+, `com.diskreid.vrcnextmobile`, versionCode11.
Подписанная тестовая debug-сборка. Подпись совпадает с0.2.7 и предыдущими версиями.
Обновление устанавливается поверх текущего приложения без удаления данных.

Исправлено короткое нажатие на человека в графе «Диаграмм»: профиль открывается
один раз и остаётся открытым, включая узлы у края обычной и полноэкранной карты.
Открытие перенесено с отпускания пальца на завершающий браузерный клик,
чтобы он не попадал в фон или кнопки только что появившегося профиля.

Удержание500мс, подсветка связей, перетаскивание, pinch, клавиатура и Back сохранены.
Отменённый жест не открывает профиль. Значки платформ не менялись:
доступный VRChat API не различает ПК без шлема и SteamVR у другого пользователя.
SteamVR-службы ПК VRCNext получают только локальные данные OpenVR.

Проверки:286 Vitest;22 сценария графа, включая полную цепочку касаний Chromium/CDP;
10 проверок интеграции графа и значков платформ в двух ориентациях;32 native JUnit.
Android Lint:0 ошибок/9 предупреждений. APK v2-подпись и все30 production assets
проверены. Полный UI-набор в этой версии повторно не запускался: проверены32
сценария затронутой функциональности. Физический Tecno/HiOS и живой аккаунт
этой версией не проверялись. Браузерный ввод не заменяет проверку телефона.
