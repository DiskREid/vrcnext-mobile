# VRCNext Mobile 0.2.6

[Скачать APK](https://github.com/DiskREid/vrcnext-mobile/releases/download/v0.2.6/VRCNext-Mobile-0.2.6.apk) ·
[Исходники ZIP](https://github.com/DiskREid/vrcnext-mobile/releases/download/v0.2.6/VRCNext-Mobile-0.2.6-source.zip) ·
[Контрольные суммы](SHA256SUMS.txt)

Android 8/API26+, WebView109+, пакет `com.diskreid.vrcnextmobile`, versionCode9.
Подписанная тестовая debug-сборка. Подпись совпадает с0.2.5; устанавливайте поверх
текущей версии без удаления приложения, сессии и локальной истории.

- Исправлен Invite Self404: документированный маршрут и полный адрес инстанса.
- Переход из профиля друга сохраняет именно его инстанс; RequestInvite,
  InviteFriend и InviteSelf выполняют разные операции без выбора другой цели.
- Избранные друзья: заполненная звезда, категории, удаление, состояние после
  повторного открытия и отметка в общем списке, защита от запоздалых ответов.
- Фото, Prints и галерея групп открываются на весь экран: pinch/pan, X/Назад,
  скачивание настоящего оригинала в Pictures/VRCNext. Без Share/жестов закрытия.
- Boop: превью стандартных, своих и коллекционных эмодзи; точный выбранный
  payload, ошибки/429 не подменяются стандартной отправкой.
- Граф: кешированные аватарки в кругах, ники под ними, прямой профиль,
  одна кнопка проверки, RAF-transform и сгруппированные SVG-связи.
- Уведомления: категории, новые сверху, отметки непрочитанных и переходы
  к группе, пользователю или календарному мероприятию.
- Отдельный недоступный ПК-журнал убран из навигации; IndexedDB, лента,
  наблюдения и диаграммы сохранены, переходы сайт/игра исправлены.

Ограничения: API не телепортирует запущенный VRChat — инвайт нужно принять
в игре; закрытый/удалённый инстанс может вернуть настоящий404. Boop поддерживает
эмодзи, а не произвольные стикеры. Скачивание возможно при известном оригинале,
до32МБ; миниатюра Print не выдаётся за оригинал. Полный ПК-журнал требует
локальных output_log_*.txt. Плавность на физическом Android и запись в реальную
галерею Tecno/HiOS ещё не измерялись; живой аккаунт этой средой не проверен.

Проверки: 283 Vitest, 92 Playwright в двух ориентациях, 32 native JUnit;
Android Lint — 0ошибок/9предупреждений. Проверены точные запросы/частичные ошибки,
повторное избранное/откат, выбранный Boop, категории, fullscreen/pinch/Back,
скачивание оригинала и отсутствие перестройки дочернего DOM графа при движении.
Подпись APK v2 и все30 production assets сверены. Тестовый instrumentationAPK
скомпилирован, на устройстве не запускался.
