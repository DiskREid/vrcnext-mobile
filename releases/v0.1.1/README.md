# VRCNext Mobile 0.1.1

[Скачать APK](https://github.com/DiskREid/vrcnext-mobile/raw/refs/heads/main/releases/v0.1.1/VRCNext-Mobile-0.1.1.apk) ·
[Скачать исходники](https://github.com/DiskREid/vrcnext-mobile/raw/refs/heads/main/releases/v0.1.1/VRCNext-Mobile-0.1.1-source.zip)

Android8/API26+, System WebView109+. Пакет `com.diskreid.vrcnextmobile`, versionCode2.
Это тестовая debug-сборка. Подпись совпадает с0.1.0; установка поверх неё проверена
в Android13-эмуляторе. Удалять приложение для обновления не требуется.

## Изменения

- Исправлена потеря сессии между паролем и кодом из письма: документированные cookie
  без серверного Secure принимаются от фиксированного HTTPS API и ужесточаются локально.
- Сессия подтверждения восстанавливается; неверный код можно повторить без её сброса.
- Пустая установка сразу показывает форму без анонимного сетевого запроса.
- Добавлены локальная диагностика, ручное восстановление WebView и защита от поздних
  заданий после остановки нативного bridge.
- Убраны запуск ПК-клиента/VR-режима и OSC.
- Добавлена справка для Google-аккаунтов. Прямой Google-вход не реализован;
  вход в официальном браузере не переносит сессию в приложение.

После обновления начните новый вход и используйте свежий код из последнего письма.
Пароль и коды в чат отправлять не нужно. Диагностика доступна на экране входа
и в настройках, копируется вручную и не содержит данных сессии.

## Проверки и ограничения

43 API-теста,25 нативных unit-тестов и6 браузерных UI-сценариев прошли.
Android-тест запуска исполнился, но завершился ошибкой callback WebView; локально
зафиксировано падение рендерера. Отдельный минимальный контрольный WebView тоже
потерял рендерер в этой среде. Это не подтверждает точную причину разового вылета
Tecno/HiOS и не доказывает успешный вход настоящего аккаунта.
