## Исправления

- Устранена причина `Malformed URL`: двоеточие между worldId и instanceId больше
  не кодируется в REST-маршруте чтения инстанса и приглашения себе.
- В профиле показаны доступный создатель инстанса с именем/аватаркой и переходом
  в профиль, подтверждённые друзья внутри, мир/тип/числа участников/платформ.
  Раскрытые сведения остаются при ошибке запроса инстанса. Приватные/неизвестные
  данные не выдумываются, группа-владелец не заменяет неизвестного создателя.
- Исследовать → Аватары → Избранные: выбор категории с запросом её tag, отдельным
  кешем, поиском имени/автора/ID и обновлением выбранной категории.
- Активность, Лента и Activity профиля: кликабельные профиль и миры «Было → Стало»
  с настоящими названиями. Исправлено растягивание аватарок панели профиля.

Защита от снимков экрана сохранена: по умолчанию выключена; переключатель находится
в «Ещё → Настройки → Конфиденциальность» и сохраняет выбор после обновления.

222 Vitest,24 Playwright в двух ориентациях и26 JUnit прошли. Android Lint:

поля, а не фиктивные данные. [Проверки на устройстве](../../docs/DEVICE_TEST_PLAN.md).
