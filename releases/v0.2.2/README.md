Android8/API26+, WebView109+, package `com.diskreid.vrcnextmobile`, versionCode5.
Подписанная тестовая debug-сборка. Подпись совпадает с0.2.1; устанавливайте поверх
текущей версии без удаления приложения, сессии и локальной истории.

В списке инстансов мира и во вкладке инстансов группы показаны друзья данного
инстанса: аватарка, имя, статус и переход в профиль нажатием. Счётчик друзей
отдельный от общего числа игроков. Доступные Friends+/групповые/Invite-инстансы
из раскрытых местоположений друзей тоже включены в список мира.

Смена местоположения/статуса обновляет карточки через существующий список друзей
WebSocket, без новых запросов на каждую строку. Старый roster группы не удерживает
ушедшего друга в строке. Скрытые места не определяются, друзья из разных инстансов
одного мира не смешиваются, неизвестное число игроков не подменяется числом друзей.
Создание инстанса, приглашения, профиль и настройка защиты снимков сохранены.

Проверки:232 Vitest,28 Playwright в двух ориентациях,26 native JUnit; Android Lint
0ошибок/9предупреждений. Проверены реальные карточки с подменённым нативным
транспортом, переход в настоящий диалог профиля, перенос друга между строками
без повторного GET, сенсорные размеры и сохранение действий приглашения.
Подпись APK v2 и все16 production assets проверены.
[Отчёт](validation.json) · [Подробности сборки](../../docs/BUILD_REPORT.md).

Физический Tecno/HiOS и живой VRChat-аккаунт этой средой не проверены.
[Сценарии для устройства](../../docs/DEVICE_TEST_PLAN.md).

Исходники: коммит `e3b2be0efc5d720673708c0912cd4117540cfdbc`, 147 проверенных файлов,
без SDK, ключей, node_modules, кешей и старых дистрибутивов.
`screenshots/` — браузерный деморежим. `screenshots/regressions/` — отдельно
помеченные синтетические примеры новых карточек, без настоящего аккаунта.
Тестовые страницы/данные не входят в APK и не записываются в личную историю.
