Android 8/API26+, WebView109+, `com.diskreid.vrcnextmobile`, versionCode 14.
Подписанная тестовая debug-сборка с прежним сертификатом; устанавливается
поверх 0.2.10 без удаления данных.

- Полностью удалён обход профилей для сбора био и аватаров: контроллер,
  периодические проверки, очередь обхода, счётчик и кнопка.
- Лента обрабатывает реальные события WebSocket. Список друзей задаёт только
  недостающие исходные данные, обновление экрана не сканирует профили.
- После полученного события смены изображения аватара выполняется точный
  поиск по его file ID в AvatarDB, как в обработчике ПК-версии VRCNext.
  Название/автор/ID дополняют исходную запись без дубликата и смены времени.
- Старое превью не подменяет изменившееся полное изображение. Hidden/loading
  картинки не дают ложных событий; устаревшие ответы не именуют другой аватар.
- Био записывается из действительно полученного поля. Отсутствие поля не
  считается очисткой. Сохранены история, цветное сравнение и поиск по нажатию.
- Исправление ложных событий Trust Rank и остальной дизайн/функции сохранены.

У текущей изученной ПК-версии фильтр Bio уже отмечен как устаревший из-за изменений
API VRChat. Доставка каждого изменения био не гарантируется. Для этого не
используется скрытый опрос. Обычное открытие полного профиля читает данные для
его отображения; это отдельное действие пользователя.

AvatarDB может не содержать частный, удалённый или новый файл; тогда остаётся
изображение без выдуманного имени. Альтернативные базы PC не добавлены. Кеш
разрешения файла и ограничение запросов относятся только к уже полученным
событиям; без событий запросов и таймера обхода нет. История между остановками
приложения не восстанавливается по догадке.

Прошли 342 Vitest, все 132 UI-сценария в двух ориентациях, повторные 10 проверок
актуальной ленты и 34 native JUnit. Один UI-сценарий повторён после конфликта
каталогов трассировки; связанный набор 8/8 прошёл в отдельном каталоге.
Android Lint: 0 ошибок / 9 предупреждений. APK v2-подпись, сертификат обновления
и production assets проверены. Физический Tecno/HiOS и живой VRChat-аккаунт
здесь не проверялись.
