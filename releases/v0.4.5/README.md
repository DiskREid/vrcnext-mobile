# VRCNext Mobile 0.4.5 — стекло, свой профиль и история

[Скачать APK](https://github.com/DiskREid/vrcnext-mobile/releases/download/v0.4.5/VRCNext-Mobile-0.4.5.apk) ·
[Исходники ZIP](https://github.com/DiskREid/vrcnext-mobile/releases/download/v0.4.5/VRCNext-Mobile-0.4.5-source.zip) ·
[Контрольные суммы](SHA256SUMS.txt)

Android 8 / API 26+, WebView 109+, versionCode 24. Подписанная тестовая debug-сборка
с прежним сертификатом: обновляется поверх 0.4.4 без удаления данных.

- Общее стеклянное оформление панелей, карточек, форм и кнопок во всех разделах.
  Видимые самостоятельные поверхности преломляют фон, текст и фотографии
  остаются чёткими. До 12 карточных, 12 остальных и 5 навигационных линз
  одновременно; вложенные элементы используют общий материал без каскада SVG.
- Свой профиль сначала открывает полную информацию с группами, мирами
  и аватарами. Редактор доступен отдельно и сохраняет черновик при переключении.
- Экран входа следует празднику и теме: фон, иллюстрация, декор и новый логотип.
  Удалена кнопка Google, которая открывала сайт без сессии VRChat. Вход
  с логином/паролем, 2FA и восстановление сохранённой сессии сохранены.
- Собственный статус учитывает настоящий игровой адрес `currentLocation`
  и событие WebSocket `user-location`, в том числе без `userId`. Наблюдаемые
  собственные изменения поступают в ленту, посещения, Instance Activity
  и аналитику. Обход профилей друзей не добавлен.

Прошли 451 тестов логики,
220 UI-проверок в двух ориентациях,
47 native JUnit, TypeScript, Vite и сборка APK.
Android Lint: 0 ошибок, 12 предупреждений.
Файлы интерфейса внутри APK сверены побайтно с готовым dist.

Пиксельные сравнения настоящих карточек, панелей «Ещё», настроек и поиска
проверяют искривление фона при неизменных непрозрачных штрихах текста.
Проверены форма входа с 2FA, свой профиль, события аккаунта, локальное
сохранение и готовый dist с исходным CSP. Данные API в проверках синтетические.

История собирается, пока приложение открыто и получает реальные сведения.
Фонового сервиса и импорта ПК-логов нет. Ненаблюдавшиеся посещения и встречи
не восстанавливаются; встреча требует доступного API адреса друга в том же
инстансе. Приватность и скрытые присутствия не обходятся. Исправление лога
смены аватаров друзей этим выпуском не заявляется.

Физический Tecno Spark 20 Pro / Android 13 HiOS, живой аккаунт VRChat, реальные
FPS, нагрев и батарея здесь не проверены. Преломление — двумерная имитация;
облегчённые эффекты и неподдерживаемый WebView используют запасное оформление.
Полноэкранные фото и граф не искажаются. Системная заставка и лаунчер сохраняют
ограничения 0.4.4. Механизм хранения сессии не менялся.
