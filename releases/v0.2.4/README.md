Android 8/API 26+, WebView 109+, пакет `com.diskreid.vrcnextmobile`, versionCode 7.
Подписанная тестовая debug-сборка. Подпись совпадает с 0.2.3; устанавливайте поверх
текущей версии без удаления приложения, сессии и локальной истории.

Исправлена ошибка 0.2.3: друг, находящийся только на сайте/в приложении VRChat,
показывался офлайн в списке и отсутствовал во вкладке «На сайте», хотя полный
профиль показывал сайт. Сокращённый ответ списка не содержит state; теперь
учитывается категория API: online включает игру и сайт. При дублировании ID
сохраняется online-запись. Настоящие офлайн-друзья остаются серыми при любом
выбранном цветном статусе. Дополнительные запросы на каждый профиль не добавлены.

Проверки: 248 Vitest, 48 Playwright в двух ориентациях, 28 native JUnit;
Android Lint — 0 ошибок / 9 предупреждений. Новые UI-сценарии запускают полный App
с реальными загрузчиком друзей, фильтрами и профилем через подменённый транспорт;
проверяют ответы без state, дубликаты, живые переходы и гонку REST/WebSocket.
Подпись APK v2 и все 16 production assets проверены. Instrumentation APK
скомпилирован, на устройстве не запускался.
