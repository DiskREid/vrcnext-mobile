# VRCNext Mobile 0.2.12

Android 8/API26+, WebView109+, `com.diskreid.vrcnextmobile`, versionCode 15.
Подписанная тестовая debug-сборка с прежним сертификатом; устанавливается
поверх 0.2.11 без удаления данных.

- Исправлены пропущенные современные `friend-update` с `iconUrl`, сравнение
  полного/уменьшенного изображения и исходный снимок при подключении.
- Пользовательская иконка подтверждается как аватар перед записью. Непроверенная
  старая фотография скрыта до подтверждения, новое событие при этом не блокируется.
- Название ищется по точному файлу: AvatarDB → avtr.icu → официальный файл VRChat.
  Настоящее название доступно и без avatar ID; недоступный ID не выдумывается.
- Карточка показывает предыдущий → новый, изображения и доступные названия.
  Оба названия открывают поиск. Уточнение сохраняет исходные ID/время события.
- Поздние ответы привязаны к своему событию и стороне; A → B → C не смешивает
  аватары. Обход профилей, счётчик и кнопка проверки не возвращены.
- Сохранены история, исправление Trust Rank и остальные функции/дизайн.

После реального события разрешаются только его файлы, с объединением запросов,
кешем и ограничением частоты. Без событий нет обхода и запросов. Если файл не
раскрыт сервером или базами, название/ID не угадываются. Подписанная база vrcndb
с приватными ключами не перенесена. Био фиксируется только из полученных полей;
у текущей ПК-версии этот фильтр уже отмечен устаревшим из-за изменений API.

Прошли 362 тестов логики, 142
проверки интерфейса в двух ориентациях, отдельные 20 проверок ленты и
36 native JUnit. Android Lint:
0 ошибок / 9 предупреждений.
APK v2-подпись, сертификат обновления и все production assets сверены.
Реальный публичный lookup AvatarDB проверен; физический Tecno/HiOS и живой
VRChat-аккаунт здесь не проверялись.
