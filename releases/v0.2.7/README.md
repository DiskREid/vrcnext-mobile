# VRCNext Mobile 0.2.7

Android8/API26+, WebView109+, пакет `com.diskreid.vrcnextmobile`, versionCode10.
Подписанная тестовая debug-сборка. Подпись совпадает с0.2.6 и предыдущими версиями;
устанавливайте поверх текущей версии без удаления приложения и локальных данных.

- Граф: обычное нажатие открывает полный профиль, удержание 500 мс выделяет
  прямые известные связи и соседей. Подсветка остаётся после отпускания, X снимает её.
- Перемещение, второй палец и отмена касания отменяют удержание. Карта не
  сдвигается под пальцем; выбранный для проверки человек и фокус связей сохраняются.
- «На весь экран» разворачивает карту на всю область приложения в обеих
  ориентациях. Профиль открывается поверх; X/Назад закрывают верхнее окно.
- Значки ПК, Android, iOS и сайта заменяют текстовые значения текущей/последней
  платформы в профиле. Доступные названия сохранены для программы чтения экрана.
- Кеш аватарок, сгруппированные линии и RAF-перемещение сохранены.
  Предыдущие функции0.2.6 не переписывались.

API обычно не сообщает, используется ли VR-шлем: Windows может быть со шлемом
или без, Android — телефоном или Quest. Значок VR предусмотрен только для явного
значения `vr`, если оно придёт с сервера. Системные панели Android сохраняются.
Граф показывает только известные связи, не выполняет скрытого обхода всех друзей.
Физический Tecno/HiOS, аппаратный Back и живой аккаунт этой средой не проверены.

Проверки:286 Vitest,108 Playwright в двух ориентациях,32 native JUnit;
Android Lint0 ошибок / 9 предупреждений. APK v2-подпись совпала с0.2.6,
все30 production assets сверены побайтово; синтетические фикстуры в APK не входят.
