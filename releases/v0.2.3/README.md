Android 8/API 26+, WebView 109+, пакет `com.diskreid.vrcnextmobile`, versionCode 6.
Подписанная тестовая debug-сборка. Подпись совпадает с 0.2.2; устанавливайте поверх
текущей версии без удаления приложения, сессии и локальной истории.

Из карточки мира можно пригласить себя и выбранных друзей в конкретный инстанс,
включая только что созданный. Телефон не должен находиться в игре. При частичной
ошибке повторяются только неотправленные приглашения, без повторного создания.

Создание группового инстанса использует действительный ID группы и доступные
пользователю права. Поддерживаются тип доступа, роли и минимальная
производительность аватара Good/Medium/Poor. Ограничение сверяется с ответом
сервера до автоматического приглашения; непроверенное ограничение не выдаётся
за успешно применённое. Фактический доступ зависит от прав аккаунта и API VRChat.

Статус и присутствие разделены: офлайн — серый индикатор, сайт — полое кольцо,
игра — цветная точка. Изменения друзей обновляют открытый профиль.
Аватарки восстанавливаются после временного сбоя, используют запасной URL,
ограниченный кеш и превью 256 px. Ушедшие за экран запросы отменяются,
а уже загруженные аватарки сохраняются при прокрутке.

Проверки: 244 Vitest, 44 Playwright в двух ориентациях, 28 native JUnit;
Android Lint — 0 ошибок / 9 предупреждений. Подпись APK v2 и все 16 production
assets проверены. Instrumentation APK скомпилирован, на устройстве не запускался.

`screenshots/` — браузерный деморежим. `screenshots/regressions/` — отдельно

аккаунта. Тестовые страницы и данные не входят в APK и личную историю.
