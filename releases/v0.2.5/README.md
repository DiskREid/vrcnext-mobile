Android 8/API 26+, WebView 109+, пакет `com.diskreid.vrcnextmobile`, versionCode 8.
Подписанная тестовая debug-сборка. Подпись совпадает с 0.2.4; устанавливайте поверх
текущей версии без удаления приложения, сессии и локальной истории.

Исправлены общие группы в профиле: используются признак mutualGroup,
пересечение с собственными группами и загруженные страницы mutual API.
Канонические grp ID поддерживают вложенные объекты и строки членства.
Ошибка одного источника сохраняет известные общие группы, заявки не считаются
членством. Участие друга не выдаётся за ваше. В полной карточке неизвестное
участие проверяется, а свежий ответ сервера заменяет старую подсказку.

Mutual Friend Network получил список для телефона и граф с карточкой выбранного
человека. Профиль и проверка общих друзей открываются явными действиями.
«Показать связи» выделяет окружение человека, «Все связи» возвращает общий граф.
Улучшены расстояния, автоматический масштаб небольшого графа и читаемость имён.
Жесты сохранены; выбор не сбрасывает координаты/масштаб. Фильтры берут текущее
присутствие, исторические данные не выдаются за онлайн. Автоматического массового
опроса нет; сохраняются только подтверждённые связи.

Проверки: 256 Vitest, 60 Playwright в двух ориентациях, 28 native JUnit;
Android Lint — 0 ошибок / 9 предупреждений. Проверены ошибки403/503, пагинация,
сверка участия с полной группой, жесты, список/граф, поиск, фокус, фильтры,
размер узлов и отсутствие перекрытия имён небольшого графа.
Подпись APK v2 и все 16 production assets проверены. Instrumentation APK
скомпилирован, на устройстве не запускался.
