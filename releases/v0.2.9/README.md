# VRCNext Mobile 0.2.9

Android8/API26+, WebView109+, `com.diskreid.vrcnextmobile`, versionCode12.
Подписанная тестовая debug-сборка. Подпись совпадает с0.2.8 и предыдущими версиями;
обновление устанавливается поверх без удаления данных.

- Исправлено получение аватаров и Bio в ленте: публичные профили проверяются
  по очереди при активном приложении, обновления списка друзей сравниваются.
- Аватар показывает доступные название, автора и превью. При получении точных
  данных исходная запись дополняется без дубликата и сохраняется после перезапуска.
- Нажатие на название открывает поиск AvatarDB, реальные результаты и карточку
  аватара. Запросов к базе до нажатия нет; ошибки и ограничения поиска показаны.
- В изменениях Bio удалённое выделено красным, добавленное зелёным. Сохранены
  кириллица, эмодзи, переносы, очистка Bio; сравнение считается по раскрытию карточки.
- Исправлен сброс свежего исходного снимка после возврата из фона.
  В фоне запросов нет, старые ответы не применяются к новому аккаунту/сигналу.

Проверки выполняются постепенно: не чаще одного профиля за 10 секунд, обычный повтор не
раньше 5 минут, сигналы объединяются с кешем 2 минуты. Для большого списка обход
дольше. Первая проверка создаёт исходный снимок, пропущенная история не выдумывается.
Название/ID доступны только если API их вернул. При одном изображении событие
помечено как обновление изображения. AvatarDB может не содержать частный или новый
аватар; совпадение имени не подтверждает совпадение ID.

Прошли 320 Vitest, полный 128-сценарный Playwright в двух ориентациях, 32 native JUnit;
Android Lint: 0 ошибок / 9 предупреждений. APK v2-подпись и все 30 production assets сверены.
Физический Tecno/HiOS и живой VRChat-аккаунт здесь не проверялись.
