Android8+ (API26), Android System WebView109+, package `com.diskreid.vrcnextmobile`,
versionCode3. Тестовая debug-сборка; сертификат совпадает с опубликованной0.1.1.
Устанавливайте поверх старой версии, не удаляя приложение и его локальную историю.

Добавлены стабильная навигация со сохранением поиска/фильтров/прокрутки,
Лента, Friends Locations, все доступные категории избранного, Social, расширенный
профиль, наблюдаемая история, журнал игры, диаграммы/граф связей и события групп.

**Скриншоты разрешены по умолчанию.** Настройка:
«Ещё → Настройки → Конфиденциальность → Защита от снимка экрана».
Включение запрещает снимки/запись через Android FLAG_SECURE, выключение снимает
защиту сразу; выбор сохраняется после перезапуска и обновления. Действует также
на экране входа. В браузерных снимках ниже переключатель недоступен по возможностям
браузера; это не ограничение Android APK.

Проверки: 200 Vitest, 18 Playwright в двух ориентациях,25 native JUnit; Lint без
ошибок/9предупреждений. APK v2 signature проверена, все16 production web assets
побайтово совпадают с dist. Инструментальные тесты скомпилированы, но не запущены
на физическом устройстве. [Машиночитаемый отчёт](validation.json).

Живой аккаунт VRChat и Tecno/HiOS этой средой не проверены. История собирается
только по реальным наблюдениям мобильного приложения, пропуски не восстанавливаются.
Напоминания групп работают при открытом приложении; фонового Android push нет.
Прямого Google-входа/переноса браузерной сессии нет. ПК/OSC/SteamVR исключены.
