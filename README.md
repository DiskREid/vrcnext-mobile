# VRCNext Mobile

Неофициальная Android-адаптация [VRCNext](https://github.com/shinyflvre/VRCNext)
от shinyflvre и участников VRCNext. Версия 0.1.0, Android 8.0+ (API26), Android System WebView109+, target API35.
Исходная ПК-версия изучена на коммите `0bfb467f89caa21893769f6495abe334febe08a3`.

Это первая самостоятельная мобильная реализация, **без полного паритета с ПК**.
Интерфейс и протоколы реализованы в коде; работа с реальным VRChat-аккаунтом,
Keystore и устройством требует отдельного приёмочного тестирования.

## Что входит

- Русский сенсорный интерфейс: нижняя навигация в портретном режиме,
  боковая в альбомном, карточки и диалоги сохраняют состояние при повороте.
- Вход VRChat, TOTP/email OTP/резервный код, восстановление и выход из сессии.
- Друзья, поиск людей, профиль, заметки, общие друзья, группы пользователя,
  приглашения, запросы приглашений, block/mute.
- Миры: поиск, популярные/активные/свои/избранные; описание, инстансы,
  создание обычных/групповых инстансов, приглашение себе и друзьям.
- Группы: поиск, членство, вступление/выход, публикации с фото, галереи,
  просмотр инстансов. Требуются соответствующие права VRChat.
- Аватары: свои/избранные, публичный поиск через avtrdb, выбор аватара,
  коллекции и переименование коллекций.
- Календарь событий и подписки; уведомления V1/V2 с действиями.
- Галерея, иконки, emoji/анимированные emoji, стикеры, prints и инвентарь;
  загрузка изображений с предпросмотром, подтверждение удаления,
  применение иконки/баннера профиля (действуют ограничения VRChat/VRC+).
- Короткие сообщения через invite-template API VRChat с cooldown.
  Это не отдельный мессенджер и не обход ограничений VRChat.
- Профиль: статус, текст, bio, местоимения, языки и ссылки.
- Ручной OSC-пульт в LAN: Chatbox и параметры аватара.

SteamVR/Overlay, Space Flight, запуск программ Windows, чтение логов ПК,
статистика встреч, локальная медиатека ПК, Voice Fight и другие дополнительные
инструменты требуют отдельного переноса или PC companion. Companion **не реализован**.
Полная таблица реализованного, частичного и отсутствующего:
[docs/FEATURE_PARITY.md](docs/FEATURE_PARITY.md).

## APK

```bash
npm ci
npm run android:build
```

Результат: `artifacts/VRCNext-Mobile-0.1.0.apk`, рядом SHA256.
Скрипт проверяет подпись с помощью `apksigner`. Это подписанная **debug-сборка
для тестирования**, не production/store-релиз. Ключ debug-сборки генерируется
локально и не входит в исходный код; APK из другого окружения может потребовать
удалить ранее установленную сборку. Для стабильных обновлений выпуска нужен
собственный release keystore через Android Studio, вне репозитория.

Системные требования сборки: Node22+ (проверено24), JDK21, Android SDK35,
build-tools35.0.0 (AGP также использует34.0.0), Gradle8.11.1/AGP8.7.2.
Установите SDK через Android Studio и задайте `JAVA_HOME`/`ANDROID_HOME`.
Gradle wrapper закреплён официальной SHA256. В подготовленной облачной среде
инструменты уже находятся в `/workspace/.tools`, активируются автоматически
скриптами или вручную: `. /workspace/.tools/env.sh`.

## Разработка и проверки

```bash
npm ci
npm run dev              # интерфейс; браузер предлагает только явный деморежим
npm run build            # TypeScript + production bundle
npm test                 # API-контракты с подменённым нативным транспортом
npm run test:ui          # Chromium, обе ориентации; системный chromium либо Playwright browser
npm run android:test     # JUnit и Android Lint
npm run android:build    # синхронизация web assets, сборка и проверка подписи APK
```

UI-тесты используют `/usr/bin/chromium`, если он установлен; иначе загрузите
Playwright Chromium (`npx playwright install chromium`). Превью не передаёт
логин или пароль в браузерную сеть, демонстрационные действия не меняют аккаунт.
Тесты API проверяют реальные формы запросов, но не подменяют проверку сервера.
Приёмочные сценарии для телефона: [docs/DEVICE_TEST_PLAN.md](docs/DEVICE_TEST_PLAN.md).

## Архитектура и защита сессии

React19 + TypeScript + Vite; Android-приложение Capacitor7. REST/WebSocket
выполняются нативным OkHttp, напрямую через `api.vrchat.cloud`/
`pipeline.vrchat.cloud`, без промежуточного сервера. Пароль не сохраняется.
Cookie `auth` и `twoFactorAuth` остаются в нативном слое; на диске шифруются
AES-GCM ключом Android Keystore. Прямой запрос токена через `/auth` запрещён.
Защищённые изображения загружаются нативно с проверкой URL/редиректов и
ограниченным кешем. Cookie не передаются базе аватаров или произвольным хостам.
Публичные картинки сторонних авторов могут загружаться с их HTTPS-серверов.

Нет аналитики. Логирование мостовых вызовов и WebView debugging отключены,
Android backup и скриншоты приложения отключены. WebSocket приостанавливается
в фоне, восстанавливается при возвращении; фонового сервиса/системных push
пока нет. 429 соблюдается, мутации автоматически не повторяются. После выхода
кеш картинок и локальная сессия очищаются. OSC использует только явно указанный
приватный IPv4 и UDP-порт1024–65535, без автообнаружения ПК.

Для облачной проверки нужны `api.vrchat.cloud`, `pipeline.vrchat.cloud`,
`api.avtrdb.com` и серверы изображений. Ограничения сети облачной машины
не задают доступ установленного на телефоне APK. Аккаунтные данные вводятся
**только на устройстве**, не в чате и не в конфигурации сборки.
