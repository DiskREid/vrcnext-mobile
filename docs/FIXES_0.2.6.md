# Исправления и доработки 0.2.6

## Приглашения

Invite Self использует документированный `POST /invite/myself/to/{worldId}:{instanceId}`.
Старый `/instances/{location}/invite` был причиной ошибочного404. Сохраняются
структурное двоеточие, полный групповой/дружеский адрес, регион и nonce.
Запрос приглашения отправляется конкретному другу с `requestSlot`, приглашение
друга — конкретному получателю с полным `instanceId`. Пустой собственный адрес
не отправляется как действительный инстанс.

Мир, открытый из текущего инстанса профиля друга, привязан к этому адресу:
выбор другого инстанса и создание нового не предлагаются. Некорректная цель
блокируется без подмены. Обычная карточка мира сохраняет общий выбор инстанса.
Публичный API не телепортирует работающий клиент VRChat: присоединение выполняется
через принятие инвайта в игре. Закрытый/удалённый инстанс может законно вернуть404.

## Избранные друзья

Профиль и общий список используют единый кеш записей избранного из VRChat.
Звезда заполнена только при наличии настоящей записи; после повторного открытия
состояние читается из API/актуального кеша. Менеджер показывает категории, позволяет
добавить, снять одну категорию или убрать все. Удаляется ID записи избранного,
а не ID пользователя. Изменение набора тегов сохраняет остальные категории;
ошибка восстановления отображается, а состояние перечитывается. Ответы запросов,
начатых до изменения/смены аккаунта, не восстанавливают старую звезду.

## Фотографии, Prints и изображения групп

Добавлен общий полноэкранный просмотр: масштаб двумя пальцами, перемещение,
кнопки масштаба, X и общий обработчик Android Back. Перемещение не закрывает окно,
фон не закрывает его, Share не добавлен. Превью ограничены2048px для просмотра;
скачивание передаёт исходные байты настоящего оригинала без уменьшения.

На Android10+ используется MediaStore `Pictures/VRCNext`, без разрешения на чтение
чужой медиатеки. На Android8/9 запрашивается разрешение записи и выполняется
индексация сохранённого изображения. При ошибке записи незавершённый файл удаляется.
Адреса/редиректы проверяются прежним белым списком, cookie используются только
для официального API. Проверяются raster MIME/байты, размеры и предел32МБ.
Если VRChat передал только миниатюру Print, она не выдаётся за оригинал:
просмотр доступен, скачивание оригинала отключено с объяснением.

## Boop

Выбор показывает16 настоящих стандартных эмодзи, собственные загруженные и
доступные коллекционные эмодзи. Передаётся именно выбранный `emojiId`/версия
или `inventoryItemId`. Обычные стикеры инвентаря этим API не поддерживаются.
Отклонённый вариант не подменяется стандартным Boop. Лимит429 сохраняет выбор
и блокирует повтор до указанного срока; частичная ошибка загрузки не скрывает
уже доступные варианты.

## Mutual Friend Network

Аватарки находятся внутри круглых узлов, никнеймы — под ними. Нажатие/Enter
открывает профиль. В списке сохранён выбор человека для карточки действий.
Дублирующая нижняя кнопка проверки удалена. Сцена мемоизирована, связи объединены
в несколько SVG-path, жест меняет transform через requestAnimationFrame вместо
пересоздания React-сцены на каждом движении. Используется общий ограниченный кеш
аватарных превью256px. URL из mutual API хранятся в памяти, не в истории связей.
Проверка DOM подтверждает отсутствие перестройки содержимого при перетаскивании;
частота кадров на физическом Tecno в этой среде не измерялась.

## История и журнал

ПК-версия читает `output_log_*.txt` через `VRChatLogWatcher`; REST/WebSocket
не передают полный журнал игроков/видео. Отдельный раздел и кнопка псевдосинхронизации
убраны из мобильной навигации. IndexedDB, история, лента, диаграммы и реальные
наблюдения не удаляются. Исправлены переход сайт→игра, отсутствие ложного выхода
из игры после сайта, составление адреса из одного свежего worldId+instanceId
и отказ от записи приватных/офлайн-плейсхолдеров как посещения.

## Уведомления

Категории: все, приглашения, запросы в друзья, объявления групп, календарные события.
Карточки отсортированы по времени создания от новых к старым, непрочитанные
выделены и имеют счётчик в загруженном списке. Прочтение подтверждается API.
Групповой отправитель не открывается как пользователь; календарные ссылки
приоритетно ведут к мероприятию, остальные — к известной группе/пользователю.

## Проверка и выпуск

Новые сценарии используют настоящие компоненты и API-клиент с изолированным
транспортом. Android unit/Lint/сборка и подпись проверяются отдельно от браузера.
Фикстуры не входят в APK. Подробности: [BUILD_REPORT.md](BUILD_REPORT.md).
Физический Tecno/HiOS, живой аккаунт, реальные ограничения групп и сохранение
в установленную галерею проверяются на устройстве; автоматические тесты их не заменяют.
