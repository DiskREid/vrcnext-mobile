APK: `releases/v0.2.6/VRCNext-Mobile-0.2.6.apk`, 5,627,945 байт.
SHA256: `143bf004983238b88c1abcf317e5b2787982756ad658c7861ac1c47f82330c7b`.
Пакет `com.diskreid.vrcnextmobile`, versionCode9, Android8/API26+, WebView109+,
targetAPI35. Подписанная тестовая debug-сборка; сертификат совпадает с0.2.5
и предыдущими версиями. Обновление устанавливается поверх, без удаления данных.

Новые UI-сценарии запускают настоящие компоненты и API-клиент с изолированной
подменой транспорта: точный адрес инстанса друга при собственном offline/ingame,
канонический InviteSelf, разные requestSlot/messageSlot, категория избранного,
откат после ошибки, повторное открытие профиля, точный Boop payload, лимит429,
частичный список эмодзи, категории уведомлений и серверное прочтение.

Граф проверен на аватарки, никнеймы, прямой переход в профиль и одну кнопку
проверки. За12 кадров перемещения меняется transform сцены без изменений её
дочернего DOM. Связи объединены в SVG-path, не придуманы между соседями.
Проверены масштаб двумя пальцами и отсутствие открытия профиля после перетаскивания.
Это не измерение частоты кадров на физическом Android.

Просмотр изображений проверен для фото, Prints и группы: полный размер окна,
pinch/pan, X/Escape как путь общего обработчика Back, отсутствие Share/закрывающих
жестов, передача настоящего оригинала скачиванию, ошибка разрешения и запрет
выдавать миниатюру Print за оригинал. JUnit проверяет boundedread и имена файлов;
MediaStore/реальное разрешение Android8/9 требуют устройства.

Сохранены проверки присутствия, групп, аватарных категорий, истории IndexedDB,
создания инстансов, календаря, диаграмм, защиты экрана и навигации. Поправлена
совместимость значка избранного с доступным именем заголовка друга.
Последовательный финальный UI-прогон использует отдельный порт5186, чтобы чужое
завершение Vite не прерывало проверку. Предыдущие незавершённые параллельные
запуски не засчитаны как успешный финальный результат.

## Ограничения

Физический Tecno Spark20Pro/Android13 HiOS, живой VRChat-аккаунт, фактическое
принятие инвайта, серверные ограничения Boop, запись в установленную галерею
и аппаратный Android Back здесь не проверялись. Публичный API не телепортирует
VRChat. Закрытый/удалённый инстанс может дать настоящий404. Boop поддерживает
эмодзи, а не произвольные стикеры. Оригинал скачивается только когда API передал
его адрес; предел32МБ. Полный ПК-журнал требует локальных output_log_*.txt;
отдельная страница удалена, реальные наблюдения/история/диаграммы сохранены.

Исторический программный эмулятор0.1.1 терял WebViewrenderer даже в контрольном
APK; это не проверка0.2.6 и не установленная причина разового вылета на Tecno.
[FIXES_0.2.6.md](FIXES_0.2.6.md), [DEVICE_TEST_PLAN.md](DEVICE_TEST_PLAN.md).

## Дистрибутив

`releases/v0.2.6`: APK, sourceZIP, SHA256SUMS, validation.json и помеченные
браузерные снимки. ZIP исключает ключи, SDK/JDK, .git, node_modules, кеши и старые
дистрибутивы. Предыдущие версии сохранены. GitHub Actions публикует версию
в GitHub Releases и сверяет размеры/SHA256 вложений; полные архивы каталогов
сохраняют все снимки. Повторная публикация не заменяет прежние файлы.
