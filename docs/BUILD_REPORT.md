## Воспроизведение и исправление

До исправления настоящий тап Chromium/CDP по узлу у края альбомного графа
давал `pointerdown(node) → pointerup(svg) → click(new modal-backdrop)`.
Действие открытия профиля записывалось, но через350мс диалог уже отсутствовал.
Ошибка воспроизведена для обычной и полноэкранной карты. Старые тесты отправляли
отдельные синтетические pointer-события без завершающего браузерного клика.

Теперь профиль открывается в обработчике клика графа. Проверки используют
настоящий browser touch input, подтверждают ровно одно открытие, сохранение
диалога после совместимого клика и отсутствие попадания в новую подложку.
Удержание, drag, pinch и следующий короткий тап проверены полной цепочкой CDP.
Клавиатура, Back, положение узлов и покадровый transform также проверены.
Синтетические сценарии дополнены завершающим click для тапов/отменённых жестов.

Дополнительно проверены навигация «Диаграмм», выбранный человек, API-проверка
общих друзей только по запросу и присутствие. Значки платформ не изменены:
у доступного API нет надёжных данных о SteamVR/шлеме другого пользователя.

## Ограничения и дистрибутив

Физический Tecno Spark20Pro/Android13 HiOS, живой VRChat-аккаунт и аппаратный
Back здесь не проверялись. Chromium/CDP воспроизводит браузерную цепочку ввода,
но не является запуском APK на телефоне. Остальные ограничения API сохранены.
