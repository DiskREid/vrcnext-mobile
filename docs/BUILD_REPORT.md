## Регрессия статусов

До изменения четыре новые браузерные проверки воспроизвели неверную подпись
«На сайте» у друга в приватном игровом инстансе и отсутствие настоящего
пользователя сайта в полосе главной. Дополнительный unit-тест обнаружил
неверную текстовую подпись traveling без state.

После исправления четыре новые и четыре существующие проверки статусов
прошли в двух ориентациях. Покрыты private, traveling, раскрытый адрес,
присутствие в игре без location по friend-online, сайт, офлайн, совпадение
с полным профилем, счётчик, живые переходы и устаревший REST-ответ после
нового WebSocket-события. До нажатия на друга запросов его профиля нет.
Синтетические снимки интерфейса проверены визуально.

Полный набор UI в этом небольшом исправлении повторно не запускался.
В 0.2.12 прошли142 проверки полного набора; текущий выпуск проверяет
изменённую логику присутствия и общую Android-сборку.
Физический Tecno Spark20Pro/Android13 HiOS, живой VRChat-аккаунт и
Android instrumentation здесь не проверялись.

## Дистрибутив

`releases/v0.2.13`: APK, исходникиZIP, SHA256SUMS, validation.json и снимки
синтетической главной. Исходники побайтово сверяются с git-коммитом,
исключают ключи, SDK/JDK, .git, node_modules, кеши и прежние дистрибутивы.
GitHub Actions публикует настоящий GitHub Release и сверяет SHA256/размеры
вложений. Старые релизы не заменяются.
