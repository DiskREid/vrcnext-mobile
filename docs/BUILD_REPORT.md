## Исправление Trust Rank

Шесть новых тестов наблюдателя проверяют цикл пустых тегов списка друзей и
заполненных тегов публичного профиля, первый исходный снимок, сохранение ранга
при неполном ответе, эквивалентные наборы/порядок тегов, настоящий переход между
известными рангами и сброс после остановки наблюдения. Отдельные четыре теста
проверяют определение ранга и ограниченный фильтр старых неподтверждённых строк.

Лента проверяется настоящими App, API-клиентом, планировщиком и IndexedDB,
с изолированным синтетическим транспортом. Фикстура теперь воспроизводит
документированное различие `friend.tags: []` и `profile.trustTags`, которое было
пропущено в предыдущей версии. Это также усилило шесть прежних проверок био,
аватаров, уточнения записи, ошибок, пауз и сохранения.

Четыре новые UI-проверки в двух ориентациях подтверждают отсутствие ложных
рангов при ручном и автоматическом обновлении, сохранение изменений био и
аватаров, скрытие прежнего шума после повторного открытия. Четыре исходные
записи остаются в реальной IndexedDB, а интерфейс показывает только
подтверждённую смену ранга и событие био. Ни одна строка базы не удаляется.

Полный132-сценарный прогон дополнительно проверяет инвайты, избранное, группы,
присутствие, граф/реальные касания, Boop, уведомления, изображения, календарь и
навигацию. Снимки интерфейса используют синтетические данные; фикстуры не
входят в APK. [Исправление и источники API](FIXES_0.2.10.md).

## Ограничения

Пустые теги не позволяют отличить Visitor от отсутствующих данных. Переход к
Visitor по пустому ответу не объявляется. Старые записи с обеими непустыми
сторонами и нераспознанным рангом сохраняются в отображении. Скрытые оригиналы
остаются в базе.

Профили проверяются по очереди при активном приложении; для большого списка
полный обход занимает дольше пяти минут. Первый снимок и перерывы не создают
прошлую историю. Физический Tecno Spark20Pro/Android13 HiOS и живой аккаунт
VRChat этой версией здесь не проверялись. [План телефона](DEVICE_TEST_PLAN.md).

## Дистрибутив

`releases/v0.2.10`: APK, sourceZIP, SHA256SUMS, validation.json и снимки
синтетических сценариев ленты. ZIP исключает ключи, SDK/JDK, .git, node_modules,
кеши и предыдущие дистрибутивы. GitHub Actions публикует настоящий GitHub Release
и сверяет размеры/SHA256 вложений. Прежние версии не заменяются.
