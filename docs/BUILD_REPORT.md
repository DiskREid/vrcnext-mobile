## Android-проверка и её ограничения

Использовался Android13/API33 x86_64, WebView109.0.5414.123, программный эмулятор
без KVM. Холодный запуск и UI-автоматизация существенно тормозили.
Нельзя объявлять нативный UI, поворот/Back или успешный холодный запуск проверенными
на основании установки, PID либо завершения adb с кодом0.

AndroidJUnit действительно исполнил тест, но callback evaluateJavascript не
завершился за10сек. Локальный отчёт приложения отдельно записал
`WebView renderer stopped. didCrash=true`. Это подтверждает падение рендерера
в этом прогоне; исходная причина и связь с разовым вылетом Tecno не установлены.
Отдельный контрольный APK с тем же FLAG_SECURE, включённым JavaScript и простым
HTML в памяти также сообщил CONTROL_PAGE_TIMEOUT и CONTROL_RENDERER_GONE. Он не
содержит кода VRCNext, его JavaScript или API. Это подтверждает независимую
проблему WebView в данном эмуляторе, но не устанавливает причину разового
физического вылета Tecno. Native UI/поворот на телефоне остаются непроверенными.
Тест не пропущен и не заменён тривиальной проходящей проверкой.

JavaScript-UI проверен отдельно в Chromium. JUnit проверяет реальное принятие
документированных cookie без Secure и их передачу между запросами, но не выполняет
Android Keystore или настоящий API. Для живого аккаунта нужны сценарии
[DEVICE_TEST_PLAN.md](DEVICE_TEST_PLAN.md).

## Исправления

- Документированные auth/twoFactorAuth-cookie без Secure больше не отбрасываются.
  Они локально получают Secure/HttpOnly и точный HTTPS API-host.
- Pending2FA не стирается при ошибке кода; этапы ошибки различаются, пустая
  установка не делает анонимный запрос перед показом формы.
- Добавлены ограниченная локальная диагностика, ручное восстановление WebView
  и отмена поздних задач при уничтожении bridge.
- ПК-запуск, VR-режим и OSC исключены по уточнению пользователя.
- Google-справка ведёт на официальный сайт, не обещая переноса его сессии.

Пользователь сообщил о разовом вылете0.1.0 на Tecno Spark20Pro/Android13 HiOS и
об отказе Email OTP. Ошибка cookie подтверждена спецификацией; стек исходного
вылета Tecno не получен, исправление его точной причины не заявляется.
Сохранение/восстановление Keystore, аккаунтные изменения, WebSocket,
изображения/VRC+, права групп требуют проверки на устройстве после входа.
