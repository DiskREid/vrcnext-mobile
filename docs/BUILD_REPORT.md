## Новые сценарии

Граф: короткий тап и Enter открывают полный профиль; удержание выделяет
только прямые известные связи и соседей. Отпускание после удержания, drag,
второй палец и pointercancel профиль не открывают. Проверены сохранение
координат карты и узлов, выбранного для проверки человека и сфокусированного
набора связей при удержании другого узла.

Полноэкранное окно занимает весь viewport в двух ориентациях. Общий модальный
стек удерживает фокус и блокирует прокрутку под картой. Профиль действительно
выше графа: проверяется не только DOM-visible, но и elementFromPoint.
Escape через путь обработчика Android Back закрывает сначала профиль,
затем карту, восстанавливая прокрутку. Проверена отдельная кнопка выхода.

Значки платформ проверены для ПК, Android, iOS, сайта, явного `vr`, неизвестных
и отсутствующих значений. Сохранены текущая/последняя платформа и статус
присутствия; Windows/Android не выдаются за подтверждённый VR-режим.

Сохранены предыдущие сценарии инвайтов, избранных, Boop, уведомлений,
полноэкранных изображений, присутствия, групп, истории, календаря и навигации.
За 12 кадров перемещения графа меняется transform сцены без изменений её
дочернего DOM. Это не измерение FPS на физическом Android.

Финальный UI-прогон выполнен последовательно на отдельном порту 5187 после
завершения правок исходников. Возврат фокуса после закрытия профиля не прокручивает карту.
Синтетические сценарии не используют аккаунт и не входят в APK. Новые снимки показывают именно такие данные.

## Ограничения

Физический Tecno Spark20Pro/Android13 HiOS, живой VRChat-аккаунт и аппаратный
Back здесь не проверялись. Полноэкранный режим занимает область приложения,
системные панели Android остаются. Публичный API обычно сообщает платформу
сборки без сведений об использовании VR-шлема.

Остальные ограничения API описаны в [FIXES_0.2.6.md](FIXES_0.2.6.md).

## Дистрибутив

`releases/v0.2.7`: APK, sourceZIP, SHA256SUMS, validation.json и новые помеченные
синтетические снимки. ZIP исключает ключи, SDK/JDK, .git, node_modules, кеши
и прежние дистрибутивы. Предыдущие версии сохранены. GitHub Actions публикует
версию в GitHub Releases и сверяет размеры/SHA256 вложений; полный архив
каталога сохраняет снимки. Повторная публикация не заменяет прежние файлы.
