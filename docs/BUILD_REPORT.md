# Проверка сборки0.2.5

APK: `releases/v0.2.5/VRCNext-Mobile-0.2.5.apk`, 4,612,090 байт.
Пакет `com.diskreid.vrcnextmobile`, versionCode8, Android8/API26+, WebView109+,
target API35. SHA256: `b08da01ccf45bf0dacca8d3d802b423fd743c3ec4088340b836c0e8b7d1be7ce`.

Подписанная тестовая debug-сборка. APK Signature Scheme v2 проверена;
сертификат SHA256 `da079fb018189e9c847a3a7eac6f934b43ba564ec679fd9f9f4f64f35a6b3d94`
совпадает с0.2.4 и предыдущими опубликованными версиями. Код7→8, package не изменён.
Устанавливать поверх текущей версии без удаления данных. Фактическая установка
обновления на физическом HiOS в этой среде не проводилась.

Новые сценарии групп проверяют настоящий профиль и полную карточку группы:
mutualGroup, собственные членства, вложенные ID, пагинацию после100 строк,
заявки/приглашения, ошибки403/503 и явный myMember:null поверх старой подсказки.
Отдельные GET деталей до открытия группы не выполняются; известные общие группы
сохраняются при отказе другого источника.

Сеть друзей проверена списком и графом: крупные строки, выбор без открытия модали,
явный переход в профиль, запуск проверки только по кнопке, фокус после поиска,
возврат общего графа, отсутствие выдуманной связи между соседями, текущие фильтры
игра/сайт/офлайн и неизвестное присутствие людей из старых снимков. Сохранены
проверки масштаба, жеста двумя пальцами и стабильных координат при выборе.

Новая регрессия запускает полный App с подменённым транспортом API. Online-ответ
содержит LimitedUserFriend без state: сайт имеет location offline, игра — private,
настоящий офлайн возвращается отдельной категорией и сохраняет цветной status.
Проверены вкладки до открытия профиля, совпадение списка и профиля, приоритет
онлайн-дубликата, живые переходы и событие во время REST-обновления. Прежний
профильный тест с заранее заполненным state сохранён как отдельная проверка,
но больше не подменяет проверку реального контракта списка друзей.

Проверены явный выбор инстанса и отправка приглашений из мира при собственном
offline; частичный успех списка получателей; точный group owner/access/roleIds и
minimumAvatarPerformance; полный group location; повтор только self-invite после
сбоя; отсутствие автоинвайта при неподтверждённом ограничении; сохранение результата
создания при ошибке обновления мира; отсутствие старого ограничения при смене
Group→Friends. Действия выполняются настоящими компонентами/API-клиентом с
изолированным подменённым транспортом, без настоящих отправок.

Открытый профиль проверен в состояниях offline/website/game с живой сменой данных:
серый индикатор, полый кружок и цветная точка. Имитация нативного image-моста
проверяет реальное восстановление img после первого сбоя, резервное фото,
сохранение при прокрутке и замену URL. JUnit отдельно проверяет канонизацию старых
официальных API-адресов и MIME по реальной raster signature, сохраняя запрет
произвольных хостов и не-изображений. Эти браузерные проверки не заменяют реальную
загрузку авторизованного изображения и BitmapFactory на телефоне.

Сохранены прежние проверки миграции/изоляции IndexedDB, навигации/поиска/прокрутки,
избранного, профиля, календаря, диаграмм и жестов. Синтетические тестовые данные
находятся только в отдельных HTML/тестах и не записывают пользовательскую историю.

## Ограничения проверки

Физический Tecno Spark20Pro/Android13 HiOS и живой VRChat-аккаунт здесь недоступны.
Права конкретной группы, серверное принятие ограничения, реальные приглашения,
изображения/VRC+, Keystore и поведение WebView проверяются по
[DEVICE_TEST_PLAN.md](DEVICE_TEST_PLAN.md). Ни компиляция, ни PID не считаются
успешным нативным UI-тестом. Причина разового физического вылета0.1.0 не установлена.

Исторический эмулятор0.1.1 (Android13 без KVM, WebView109) терял renderer и не
завершал JS callback; минимальный контрольный APK без VRCNext тоже терял renderer.
Это отдельный старый результат, а не проверка0.2.5 или доказательство причины сбоя
Tecno. Instrumentation0.2.5 в этой среде не запускался.

История основана на фактических наблюдениях приложения. Фоновые пропуски, скрытые
инстансы, неизвестные игроки и видео не реконструируются; фонового push нет.
Google-вход/перенос браузерной сессии не добавлены. Права и решения сервера VRChat
сохраняются. [FEATURE_PARITY.md](FEATURE_PARITY.md),
[FIXES_0.2.5.md](FIXES_0.2.5.md), [AUTHENTICATION.md](AUTHENTICATION.md).
