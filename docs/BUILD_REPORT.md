## Награды профиля

Поддержаны 10 семейств точных имён/вариантов, имена ежегодного Recap с годом
и три полные фразы описаний. Для каждого поддержанного текста предоставлены
все11 языков. Проверены неизвестные имена, описания с числом подарков/уровнем,
альтернативные поля и неизменность исходных объектов. Перевод по догадке из ID
или названия для незнакомого описания не выполняется.

Браузерный сценарий меняет все11 языков при открытом профиле без новых
запросов. Проверены скрытые награды, оригинальные пользовательские имя/био,
неизвестный текст и JSON-копия исходных API-данных. Сценарий использует
синтетические badgeName/badgeDescription и не подтверждает текущий текст
конкретной награды на живом аккаунте. Восемь прежних проверок языков/проекта
также прошли, включая сохранение правок профиля и переход на Boosty.

После уточнения названия Creator и вариантов Gifter повторно прошли шесть
проверок словаря; APK заново собран и сверен. Остальные зависимости в
package-lock сохранены без изменений. Полный UI-набор после небольшого
исправления повторно не запускался.

## Ограничения

Полный серверный каталог наград не найден. Неизвестные/новые названия и
изменившиеся описания остаются оригинальными. Пример конкретной награды от
пользователя ещё не получен; для расширения словаря нужны точные поля из
публичного профиля. Имя/описание переводятся независимо: известное название
не заменяет неизвестное описание общей фразой.

Физический Tecno Spark20Pro/Android13 HiOS и живой VRChat-профиль здесь не
проверялись. Получение лога смены аватара не менялось и не объявляется
исправленным. [Подробности](FIXES_0.3.1.md) · [План телефона](DEVICE_TEST_PLAN.md).
