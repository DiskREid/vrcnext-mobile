## Лента, публичные профили и сохранение

Новое покрытие включает:

- Сравнение реальных обновлений списка друзей и публичных профилей без открытия
  карточки пользователя; первый снимок создаёт исходные данные, не прошлое событие.
- Смена изображения без avatarID, нормализация fileID/версии, защита от ложных
  изменений размера/подписи/CDN и пользовательской иконки.
- Дополнение исходной записи настоящим названием, автором, превью и ID после
  подтверждения профилем; тот же ID/время записи, без дублирования.
- Последовательное сохранение обновлённой записи и её восстановление после
  перезапуска через настоящую IndexedDB, включая гонки загрузки/записи.
- Био, очистка био, удалённые и добавленные фрагменты, кириллица, эмодзи,
  переносы, буквальный HTML-подобный текст и ограниченная работа для длинного био.
- Ограниченные запросы, очередь с приоритетом и справедливостью, ручная проверка,
  401/403/404/429, Retry-After, отсутствие фоновых запросов и отказ от старых
  ответов после нового сигнала, смены аккаунта или ухода в фон.

Тест настоящего App нашёл гонку возобновления: профиль мог успеть создать
исходный снимок перед cleanup другого наблюдателя, который сразу его сбрасывал.
Активация перенесена в React effect после cleanup; последующее изменение био
после возврата из фона теперь фиксируется. Отдельные детерминированные тесты
проверяют планировщик и минимум10секунд между запросами, кеш2минуты и обход5минут.

## Поиск AvatarDB и прежние функции

Восемь UI-проверок поиска подтверждают запрос только после нажатия на название,
правильный query/page, точное совпадение ID, сохранение загруженного при ошибке
следующей страницы, паузу429, закрытие до ответа, вложенные модальные окна,
переход к автору и запрет внешних запросов в деморежиме.

Шесть проверок ленты (три сценария в двух ориентациях) проходят с настоящими App,
API-клиентом, планировщиком и IndexedDB, но изолированным синтетическим транспортом.
Полный128-сценарный прогон дополнительно проверил инвайты, избранное, группы,
присутствие, граф/реальные касания, Boop, уведомления, просмотр изображений,
календарь и навигацию. Финальный прогон выполнен на отдельном порту5191 после
завершения правок исходников. Фикстуры не входят в APK.

## Ограничения

Проверки профилей выполняются по очереди при активном приложении, не мгновенно.
У большого списка полный обход дольше пяти минут. Начальный снимок и перерывы
не выдумывают пропущенную историю. Название/ID доступны только если API их вернул;
AvatarDB может не содержать частный или новый аватар. Поиск не доказывает
совпадение ID по одному имени. Физический Tecno Spark20Pro/Android13 HiOS и живой
VRChat-аккаунт этой версией здесь не проверялись.
[Изменения и источники](FIXES_0.2.9.md) · [Проверка на телефоне](DEVICE_TEST_PLAN.md).
