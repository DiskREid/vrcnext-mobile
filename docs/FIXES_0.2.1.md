# Исправления по обратной связи: 0.2.1

## Местоположение и Malformed URL

В0.2.0 весь location кодировался `encodeURIComponent`, поэтому маршрут содержал
`/instances/wrld_…%3A123…`. Спецификация VRChat и InstancesAPI оригинального
VRCNext используют `/instances/{worldId}:{instanceId}`: сервер разбирает буквальное
двоеточие. Исправлены чтение инстанса и POST приглашения себе; значения сегментов
по-прежнему проверяются и экранируются отдельно. Разрешённый HTTPS host нативного
транспорта не менялся.

Карточка «Текущий инстанс» в профиле теперь независимо загружает мир и инстанс.
При ошибке инстанса остаются ссылки на мир, создателя из раскрытого location и
подтверждённых друзей внутри. Создатель определяется по реальному creatorId/полям
владельца/API или `hidden/friends/private(usr_…)`, показывается имя/аватар и переход
в профиль. Группа-владелец имеет отдельный переход в группу и не превращается в
фиктивного пользователя-создателя. Если создатель не передан, это явно указано.

Друзья внутри определяются по полному раскрытому местоположению или фактическому
roster из ответа инстанса, без объединения всех людей одного мира. Свежий профиль
просматриваемого друга заменяет старую строку. Если location отсутствует, допустим
составной адрес из worldId+instanceId того же свежего ответа. Явные private/offline
не заменяются устаревшими данными. Количество игроков, вместимость и платформы
выводятся только при наличии настоящих целых неотрицательных значений.

## Избранные аватары

В отдельном разделе «Избранное» выбор категории уже присутствовал, но в
«Исследовать → Аватары → Избранные» его не было: выполнялся общий запрос.
Добавлен пикер реальных категорий. Выбранная категория запрашивается по её tag;
кеш общего списка и каждой категории изолирован, поиск имени/автора/ID применяется
до разбиения на страницы. Недоступная категория показывает ошибку, а не все записи.

## Активность

Текущая «Активность» теперь сохраняет реальный ID/имя пользователя, предыдущее
и новое раскрытое местоположение события WebSocket до изменения строки друга.
Смена инстанса в том же мире отличается от смены мира. Профиль кликабелен.
Лента и Activity профиля используют тот же вывод миров «Было → Стало».

Настоящие названия миров разрешаются последовательной очередью только для видимых
строк, с ограниченным кешем по аккаунтам, ошибками и ручным повтором. Приватный,
offline и неизвестный адрес не становятся ссылкой. Старым событиям без целей
не приписываются вымышленные профили/миры. История и настройка снимков сохранены.

## Проверки

Контрактные тесты проверяют буквальное двоеточие и защиту маршрута; Android JUnit
проверяет реальный разбор пути OkHttp. Отдельная браузерная тестовая страница
использует настоящий API-клиент с подменённым нативным транспортом: старая форма
адреса отвечает400 Malformed URL. Проверяются владелец/друзья, ошибка403, приватный
профиль, клики реальных целей активности и разные категории аватаров. Страница
синтетическая, не сохраняет историю и не включена в APK. Итоговые числа проверок
и статус физического устройства: [BUILD_REPORT.md](BUILD_REPORT.md).
