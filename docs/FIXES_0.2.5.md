# Общие группы и Mutual Friend Network 0.2.5

## Общие группы в профиле

Ранее отметка «Общая» и соответствующая вкладка зависели только от первой страницы
отдельного mutual API. Ответ списка групп пользователя уже мог содержать
`mutualGroup: true`, но приложение не использовало этот признак. Идентификатор
членства `gmem_` также нельзя сравнивать с идентификатором самой группы `grp_`.

Теперь объединяются положительные подтверждения из трёх источников: `mutualGroup`,
пересечение доступных групп пользователя с собственными группами и загруженные
страницы mutual API. Вложенные объекты группы и плоские строки членства приводятся
к каноническому ID. Заявки и приглашения не считаются подтверждённым членством.
Страницы общих групп можно догружать; ошибка одного источника не скрывает уже
подтверждённые группы и не превращается в утверждение, что общих групп нет.
Запросы деталей на каждую строку не выполняются.

Карточка группы различает неизвестное участие и подтверждённое отсутствие
членства. Во время первоначальной проверки не предлагается ошибочное вступление.
Свежий ответ сервера, включая `myMember: null` и состояние заявки, имеет приоритет
над старой отметкой общей группы. Поля участия из строки чужого профиля
не выдаются за ваше членство. Успешное вступление/выход сбрасывает старое
состояние перед повторным чтением. Обновление профиля перечитывает источники.

## Сеть друзей на телефоне

В Mutual Friend Network появились режимы «Список» и «Граф». На узком экране
по умолчанию открывается список с крупными строками. Нажатие выбирает человека
и показывает карточку с действиями «Открыть профиль», «Показать связи» и
«Проверить общих друзей». Обычный выбор не переставляет существующие узлы и
не сбрасывает масштаб.

Граф выделяет выбранного человека и его известные связи. «Показать связи» убирает
посторонние узлы, снимает ограничивающий поиск/фильтр и показывает его окружение;
«Все связи» возвращает общий вид. Поиск в общем графе сохраняет контекст и
предлагает читаемые результаты. Сохранены перемещение пальцем, масштабирование
двумя пальцами, кнопки масштаба/сброса и клавиатурное управление.

Фильтры используют актуальное присутствие друзей: игра, сайт, офлайн или неизвестно.
Цвет выбранного статуса и сохранённая старая подпись не доказывают текущий онлайн.
Люди только из сохранённой проверки помечаются как исторические данные с неизвестным
присутствием. Проверка запускается по кнопке для одного друга; массового опроса
нет. Кеш изолирован по аккаунту, пределы, отмена и обработка ошибок сохранены.
Граф содержит только подтверждённые API связи, без выдуманных связей между всеми
людьми из одного ответа.

## Проверка

Контрактные тесты проверяют ID, объединение источников и состояния участия.
Браузерные сценарии используют настоящие компоненты и API-клиент с подменённым
транспортом: пагинация, 403/503, профиль и полная группа, жесты, выбор, поиск,
фокус, фильтры и явная проверка связей. Фикстуры не входят в APK.
Результаты: [BUILD_REPORT.md](BUILD_REPORT.md). Живой аккаунт и физический Tecno
в этой среде не проверялись.
