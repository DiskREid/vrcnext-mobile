# VRCNext Mobile 0.2.7

## Граф связей

- Короткое нажатие на круг открывает полный профиль пользователя.
- Удержание около половины секунды выделяет его прямые известные связи и соседей.
  Остальные узлы и линии приглушаются. Подсветка остаётся после отпускания;
  её можно снять кнопкой X под картой. Удержание не отправляет API-запросы.
- Подсветка отделена от выбора человека для проверки общих друзей. Карточка
  над картой не меняет размер под пальцем, а режим «Показать связи» сохраняет
  свой набор узлов при удержании другого человека.
- Перетаскивание, второй палец, отмена касания и сворачивание отменяют таймер
  удержания. Ни они, ни отпускание после удержания не открывают профиль.
- Кнопка «На весь экран» разворачивает карту на всю область приложения,
  скрывая навигацию. Масштаб, перемещение, аватарки и подсветка работают
  в обеих ориентациях. При изменении размера карта вписывается в новую область.
- X и системная кнопка «Назад» возвращают обычный граф. Профиль открывается
  поверх полноэкранной карты; сначала закрывается профиль, затем карта.
- Сохранены кеш изображений, сгруппированные SVG-линии и RAF-перемещение
  без перестройки дочернего DOM на каждом кадре.

## Значки платформ

В информации профиля значения текущей и последней платформы заменены значками:
монитор для ПК, Android, телефон для iOS, глобус для сайта. Название доступно
в подсказке и программе чтения экрана. Неизвестное значение обозначено знаком ?.
Статусы присутствия и их цвета не меняются.

Публичный VRChat API обычно сообщает платформу сборки (`standalonewindows`,
`android`, `ios`), но не различает ПК со шлемом и без него, Android-телефон
и Quest. Поэтому значок очков предусмотрен только для явного значения `vr`,
если сервер его передаст. По платформе, аватару или имени VR-режим не угадывается.

## Проверки и ограничения

Автоматические браузерные сценарии проверяют жесты, отмену удержания,
размер полноэкранного окна, порядок закрытия вложенного профиля, устойчивость
раскладки и доступные имена значков в портретной и альбомной ориентации.
Фикстуры используют отдельный синтетический транспорт и не входят в APK.

Граф показывает только известные связи из списка друзей и явных проверок
общих друзей. Отсутствующая линия не доказывает отсутствие дружбы. Полноэкранный
режим занимает WebView приложения; системные панели Android сохраняются.
Плавность и аппаратная кнопка «Назад» на физическом Tecno/HiOS здесь не проверены.
Существующие ограничения API из [0.2.6](FIXES_0.2.6.md) сохраняются.
