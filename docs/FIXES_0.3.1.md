# VRCNext Mobile 0.3.1 — перевод наград профиля

В 0.3.0 переводился интерфейс, а badgeName и badgeDescription выводились
как исходные поля API. Теперь для наград используется отдельный словарь
с переводами на все 11 языков. Он не применяется к именам, био и другому
пользовательскому содержимому.

Распознаются точные названия/варианты Early Supporter, Supporter, VRC+
Supporter/Subscriber/Gift Giver, VRChat Team/Creator/Translator, Community
Contributor и три формы названия ежегодного VRChat Recap с сохранением года.
Описания переводятся только при полном совпадении с поддержанной фразой.
Из неизвестного описания не выводятся количество подарков, стаж или уровень.
Точное исходное написание сохраняется при выборе английского языка.

Это локальный ограниченный словарь, а не полный каталог сервера. Неизвестные
и новые названия/описания остаются оригинальными. Для добавления конкретной
непереведённой награды нужны её точные badgeName и badgeDescription из
публичного JSON. Скриншот или название награды также поможет определить случай.

Профиль подписан на выбор языка: уже открытые награды меняются сразу без
повторного API-запроса. Исходные данные, JSON-копия/экспорт, скрытые награды,
изображения и порядок остаются прежними. Поддержаны также поля name,
description, imageUrl и id в альтернативной форме данных.

## Источники и проверка

Схема VRChat [Badge](https://github.com/vrchatapi/specification/blob/main/openapi/components/schemas/Badge.yaml)
описывает имя и описание без словаря языков. В текущих изученных VRCNext/VRCX
эти поля также отображаются напрямую. Публичный config не предоставил каталог
наград; несуществующий GET /badges не добавлен в приложение. Ни ID новых наград,
ни их наличие у пользователей не выдумываются: переводится только полученный текст.

Проверены точные имена/варианты, все языки, известные описания, незнакомый текст,
годы Recap и неизменность исходных объектов. Браузерный сценарий использует
синтетический публичный профиль с известной/неизвестной/скрытой наградой,
меняет все 11 языков, проверяет отсутствие новых запросов и исходный JSON.
Синтетические описания проверяют правила словаря и не являются подтверждением
того, какой текст сейчас возвращает сервер конкретному пользователю.

Физический телефон и живой профиль не проверялись. Получение лога аватаров
не изменено и остаётся нерешённым по предыдущему сообщению пользователя.
